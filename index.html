О себе

Начинала не с данных, а с си: первые учебные работы — утилиты, разбор файлов, матрицы и численные методы. Там стало понятно главное: пока задача не разложена на структуры и функции, писать нечего.

Потом были JavaScript и Java — интерфейсы, браузерная логика, первые приложения и тесты. Java приучила к типам, контрактам и к тому, что чужая ошибка должна падать на сборке, а не у пользователя.

Сейчас основной язык — Python. Он мне подходит как язык для учёного: одинаково годится и для боевого сервиса, и для расчётов, обработки и визуализации, когда гипотезу нужно проверить в тот же вечер.

Веду проект целиком: разбираю требование, выбираю структуру, пишу тесты, оформляю README так, чтобы через месяц всё ещё было понятно. Отдельно держу дисциплину кода — отсюда 24 учебных проекта с проверкой правил скриптом.

Ещё преподаю: делаю уроки и презентации по информатике для 3–11 классов и материалы для практики — это хорошо тренирует умение объяснять без терминов-заклинаний.
